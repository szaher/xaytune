## Roles and Permissions

Not applicable. xaytune is a library with no authentication, authorization, or multi-tenancy. All operations run under the invoking user's OS permissions.

## Critical Workflows

The standard user workflow through xaytune:

```
1. Install
   pip install xaytune
   pip install xaytune[all]  # for all optional features

2. Configure
   Write a YAML config file or use Python API kwargs.
   Optional: xaytune studio (Gradio UI for config creation)

3. Prepare Data (optional)
   xaytune data filter input.jsonl -o filtered.jsonl --min-chars 100
   xaytune data deduplicate filtered.jsonl -o deduped.jsonl
   xaytune data generate --mode distill --model gpt-4 -n 100 -o synth.jsonl

4. Find Learning Rate (optional)
   xaytune lr-find --config train.yaml

5. Train
   xaytune train --config train.yaml
   xaytune train --config train.yaml --resume  # resume from checkpoint
   xaytune launch --config train.yaml --nproc-per-node 4  # distributed

6. Evaluate
   xaytune eval --model output/merged --benchmarks mmlu,gsm8k
   xaytune compare output/model_a output/model_b --benchmarks mmlu

7. Export
   xaytune export merge --checkpoint output/checkpoint-500 --output output/merged
   xaytune export gguf --model output/merged --output model.gguf --quant Q4_K_M
   xaytune export push --model output/merged --repo username/my-model
   xaytune export model-merge --models model_a model_b --method slerp --output merged
```
